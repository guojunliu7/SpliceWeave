# SpliceWeave

SpliceWeave integrates short-read RNA-seq and long-read Iso-Seq evidence for transcript structure and alternative splicing analysis.

## Source code

Download the [frozen SpliceWeave 0.1.8 source archive](./SpliceWeave-0.1.8-public-source.zip). It contains the Python package source, tests, documentation, example configurations, replay inputs, a wheel, and a SHA256 manifest. The archive SHA256 is `5193b187ccf089b1043e67712878b761cdd1fe283cb89509f4499919d78dcc01`. Personal filesystem paths in configuration and replay sample tables were replaced with portable placeholders; the package source and wheel were not modified.

After extracting, verify the archive contents with `shasum -a 256 -c SHA256SUMS.txt`. Installation and replay commands are documented in `FREEZE.txt`. The frozen four-module manuscript experiment used version 0.1.7; version 0.1.8 is the subsequent frozen code snapshot.
